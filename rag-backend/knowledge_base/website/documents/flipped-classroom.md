Need for Innovation
• Traditional lecture delivery often limits student engagement in abstract OOP topics like
Inheritance.
• Students struggle to visualize hierarchical relationships through theory alone.
• To promote deeper conceptual clarity and active learning, a flipped classroom approach was
introduced.
Description of the Innovation
• Students were provided with pre-class learning materials, including short videos explaining:
o Types of Inheritance
o Base and Derived Classes
o Access Specifiers in Inheritance
o Practical examples in C++ / Java
Class time was utilized for
o Hands-on coding exercises
o Peer discussions and Q&A
o Mini case studies demonstrating inheritance in real applications

## Page 2

Objectives
• To encourage pre-class preparation for better understanding of Inheritance concepts.
• To facilitate active in-class discussion and problem solving.
• To develop students’ ability to apply OOP concepts in coding tasks.
• To improve higher-order thinking and promote self-paced learning.
Tools / Methods Used
• LMS (Google Classroom) for:
o Sharing video links, notes, and pre-class quizzes
o Collecting student reflections
• YouTube Videos for:
o Explaining conceptual content in short, engaging modules
• In-class coding practice using CodeBlocks / VS Code
• Case-based discussion method
• Peer instruction through group activities
Implementation Steps
• Uploaded curated video content on Google Classroom covering Inheritance.
• Conducted a short pre-class quiz to assess initial understanding.
• Used classroom time for:
o Solving inheritance-based coding problems
o Group activities to identify inheritance types in real-world examples
o Instructor-guided debugging sessions
• Ended the session with an exit ticket summarizing key takeaways.
Evidence of Student Engagement
• Increased pre-class resource access logs on Google Classroom.
• Active participation during coding tasks and discussions.
• Students asked more conceptual questions compared to lecture-based sessions.
• Improvement observed in in-class quiz scores.
